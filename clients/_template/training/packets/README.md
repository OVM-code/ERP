# Learning packets — self-serve per module/role

A packet is the self-study companion of a training module: generated from the
manual chapter(s) + the session exercises, for absentees, new hires and refreshers
— without booking a consultant again.

## Format — `M<x>-<slug>-packet.md`

1. **Wat je hierna kan** — the module's learning goals (from the session prep).
2. **Lees & klik** — the manual topics to read (deep links: manual chapter → topic
   codes) and the BPMN flow to click through.
3. **Doe** — the session exercises verbatim (they are already self-checking:
   concrete start data + expected result).
4. **Toets jezelf** — 5–8 quiz questions with answers at the bottom, generated
   from the manual content (answers cite the topic code).
5. **Hulp** — where to ask (aftercare register / key user), and what to do when
   stuck (the exact escalation from the manual's intro).

## Rules

- Nothing new is written for a packet — it recombines manual + exercises; if a
  packet needs content the manual lacks, that is a manual review-flag first.
- Quiz answers cite topic codes so a wrong answer points to the exact section.
- Regenerate packets when the manual bumps a version (they carry the version).
